Kebijakan Privasi

Tanggal berlaku: 12 Oktober 2026

Kebijakan ini menjelaskan bagaimana aplikasi Doubo (“aplikasi”) dan situs web ini menangani informasi Anda. Ini adalah terjemahan; jika terdapat perbedaan, versi bahasa Inggris yang berlaku.

1. Aplikasi Doubo

Aplikasi ini tidak mengumpulkan atau mengunggah data pribadi apa pun.

  • Penyimpanan di perangkat: URL playlist yang Anda tambahkan, file playlist yang diimpor, favorit, saluran yang baru diputar, riwayat playlist, dan pengaturan hanya disimpan di perangkat Anda. Anda dapat menghapusnya kapan saja di Pengaturan aplikasi.
  • Tanpa SDK analitik atau iklan: Aplikasi ini tidak berisi komponen analitik, iklan, atau pelacakan pihak ketiga.
  • Permintaan jaringan: Aplikasi hanya menghubungi URL playlist, siaran, dan logo yang Anda tambahkan atau pilih, untuk mengunduh dan memutar konten. Permintaan tersebut dikirim langsung ke server pihak ketiga terkait, yang menanganinya sesuai kebijakan privasi masing-masing (misalnya, mereka mungkin mencatat alamat IP Anda). Kami tidak melihat permintaan ini.
  • Pemeriksaan ketersediaan: Saat Anda memeriksa saluran, aplikasi mengirim sejumlah kecil permintaan ke setiap URL siaran untuk melihat apakah siaran merespons. Hasilnya hanya disimpan di perangkat Anda.
  • Jaringan lokal: Saat Anda menggunakan transmisi DLNA, aplikasi mencari TV di jaringan lokal Anda dan mengirim URL siaran ke perangkat yang Anda pilih. Ini memerlukan izin Jaringan Lokal, dan data tersebut tidak pernah keluar dari jaringan lokal Anda.
  • Akses file: Aplikasi hanya membaca file yang Anda pilih sendiri di pemilih file sistem.

2. Situs web ini

Situs web ini di-host di GitHub Pages dan menggunakan Google Tag Manager serta Google Analytics 4 untuk memahami cara situs digunakan (misalnya kunjungan, perujuk, halaman yang dilihat, dan klik pada tombol unduh) agar kami dapat memperbaikinya.

  • Informasi yang dikumpulkan: Jenis perangkat dan browser, perkiraan lokasi (tingkat kota atau negara), halaman perujuk, halaman yang dikunjungi dan interaksi, serta pengenal anonim yang disimpan dalam cookie. Google Analytics 4 tidak mencatat atau menyimpan alamat IP lengkap.
  • Cookie dan persetujuan: Kami menggunakan Google Consent Mode. Di Kawasan Ekonomi Eropa, Inggris, dan Swiss, cookie analitik hanya dipasang setelah Anda mengklik “Terima”. Di wilayah lain, Anda dapat mengklik “Tolak” kapan saja untuk menonaktifkan cookie analitik. Penyimpanan untuk iklan selalu nonaktif. Anda dapat mengubah pilihan kapan saja melalui “Pengaturan cookie” di bagian bawah halaman.
  • Pemroses: Data analitik diproses oleh Google LLC. Lihat Kebijakan Privasi Google dan Cara Google menggunakan informasi dari situs yang menggunakan layanannya. Anda juga dapat memasang Add-on Browser Pilihan Tidak Ikut Google Analytics.
  • Hosting: GitHub, sebagai penyedia hosting, dapat mencatat alamat IP pengunjung untuk keperluan keamanan dan operasional. Lihat Pernyataan Privasi GitHub.
  • Masa penyimpanan: Data Google Analytics disimpan selama 14 bulan.

3. Privasi anak

Aplikasi dan situs web ini tidak ditujukan untuk anak di bawah 13 tahun, dan kami tidak dengan sengaja mengumpulkan informasi pribadi anak.

4. Pilihan Anda

Anda dapat menghapus data aplikasi di perangkat atau menghapus aplikasi kapan saja. Untuk analitik situs web, Anda dapat menolak atau mencabut persetujuan cookie. Untuk pertanyaan atau permintaan terkait penanganan data, hubungi kami melalui halaman Dukungan.

5. Perubahan

Jika kebijakan ini berubah, kami akan memperbarui tanggal berlaku di halaman ini. Perubahan penting akan diumumkan di situs web atau dalam catatan rilis aplikasi.
