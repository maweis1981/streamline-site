Pemutar M3U online gratis, langsung bisa dipakai

Doubo versi web adalah pemutar M3U / M3U8 online yang gratis. Tanpa unduhan dan tanpa daftar: tempel tautan playlist atau impor file, lalu jelajahi grup, cari, dan tonton saluran live di browser komputer maupun ponsel.

  • Tanpa instalasi

    Berjalan di Chrome, Edge, Safari, Firefox, dan browser modern lainnya.

  • Grup dan pencarian

    Membaca grup di playlist Anda sehingga saluran mudah ditemukan meski ada ribuan.

  • Ganti jalur otomatis

    Saluran dengan beberapa tautan stream digabung, dan pemutar pindah ke tautan berikutnya bila satu tidak berjalan.

  • Mengutamakan privasi

    Playlist tetap di browser Anda. Tidak ada yang diunggah atau dikumpulkan.

Pertanyaan umum

Apakah pemutar web ini gratis? Perlu akun?

Sepenuhnya gratis dan tidak perlu akun. Buka halaman, tambahkan playlist, dan mulai menonton.

Format playlist apa yang didukung?

Playlist M3U dan M3U8, termasuk daftar IPTV dengan atribut tvg-id, tvg-logo, dan group-title. Siaran live diputar melalui HLS (.m3u8).

Di mana playlist saya disimpan?

Hanya di penyimpanan lokal browser Anda saat ini, dan tidak pernah diunggah. Jika berganti browser atau menghapus data situs, tambahkan lagi.

Mengapa beberapa saluran lebih baik ditonton di aplikasi?

Demi keamanan, browser membatasi sebagian siaran live, seperti tautan http atau jalur yang memerlukan header khusus. Aplikasi Doubo tidak punya batasan ini dan juga mendukung transmisi ke TV serta pemutaran di latar.
