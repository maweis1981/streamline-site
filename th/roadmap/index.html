แผนพัฒนา

เราให้ความสำคัญกับประสบการณ์การเล่นที่ลื่นไหลและเสถียรก่อน แล้วจึงขยายฟีเจอร์และแพลตฟอร์ม นี่คือทิศทางที่วางแผนไว้ ไม่ใช่การรับประกันวันเปิดตัว

อัปเดตล่าสุด: ตุลาคม 2026

เปิดตัวแล้ว

รากฐาน 1.0

  • นำเข้า M3U/M3U8 และกู้คืนประวัติ

    นำเข้าจาก URL หรือไฟล์ และจำเพลย์ลิสต์ล่าสุดไว้

  • กลุ่ม การค้นหา รายการโปรด ดูล่าสุด

  • ตรวจความพร้อมใช้งานแบบพร้อมกัน

  • ภาพซ้อนภาพ คำบรรยาย ความเร็วการเล่น

  • สลับสัญญาณของช่องที่ชื่อเดียวกัน

  • ส่งผ่าน DLNA และเล่นวิดีโอในเครื่อง

กำลังพัฒนา

เล่นได้ลื่นไหลยิ่งขึ้น

  • รองรับสตรีม HTTP ได้กว้างขึ้น

  • ปรับปรุงการเล่นเบื้องหลังและภาพซ้อนภาพ

  • แยกวิเคราะห์ M3U ได้ครบขึ้น

    รองรับการเข้ารหัส GBK และอื่นๆ, tvg-id และ header User-Agent / Referer รายช่อง

  • สถานะความพร้อมของช่อง

    แสดงสถานะปัจจุบันของแต่ละช่อง พร้อมจัดเก็บผล

ถัดไป

ความเสถียรและความเร็ว

  • แอป Android

    โทรศัพท์ แท็บเล็ต และ Android TV / กล่องทีวี Android

  • ช่องหลายสัญญาณพร้อมสลับอัตโนมัติ

    เลือกสัญญาณที่ลื่นที่สุดให้อัตโนมัติ

  • เก็บเพลย์ลิสต์ออนไลน์ไว้และเปิดแบบออฟไลน์ได้

  • AirPlay

  • รองรับรายการมากกว่า 10,000 ช่องอย่างลื่นไหล

  • แอปหลายภาษา

    English, จีนตัวย่อ, Bahasa Melayu, Bahasa Indonesia, Tiếng Việt และไทย

อนาคต

เนื้อหาและแพลตฟอร์มเพิ่มเติม

  • ผังรายการ XMLTV (EPG)

  • ดูย้อนหลัง (Catch-up)

    ใช้ได้เฉพาะเมื่อแหล่งสตรีมมีพารามิเตอร์สำหรับดูย้อนหลัง

  • ซิงก์ผ่าน iCloud

    รายการโปรด เพลย์ลิสต์ และการตั้งค่าในทุกอุปกรณ์

  • รองรับ Xtream Codes

  • Apple TV และ CarPlay

  • การค้นหาแบบรวม

อยากได้ฟีเจอร์อะไร แนะนำเราได้บน GitHub
