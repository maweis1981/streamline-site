คู่มืออุปกรณ์ · Kodi

วิธีเพิ่มเพลย์ลิสต์ M3U ใน Kodi ด้วย PVR IPTV Simple Client

Kodi เล่นเพลย์ลิสต์ IPTV ผ่านส่วนเสริมทางการ PVR IPTV Simple Client เมื่อตั้งค่าแล้ว ช่องต่าง ๆ จะแสดงในส่วน TV ของ Kodi พร้อมกลุ่มช่อง และผังรายการหากเพลย์ลิสต์ของคุณมีให้

สิ่งที่ต้องมี

  • Kodi บน Windows, Mac, Linux, Android, Android TV หรือ Fire TV
  • ลิงก์เพลย์ลิสต์ M3U / M3U8

ขั้นตอน

  1. 01

    เปิดหน้าเลือกส่วนเสริม

    ใน Kodi เปิด Settings (ไอคอนรูปเฟือง) → Add-ons → Install from repository → PVR clients

  2. 02

    ติดตั้ง PVR IPTV Simple Client

    เลือก PVR IPTV Simple Client แล้วเลือก Install บางระบบติดตั้งไว้แล้วและแค่ต้องเปิดใช้งาน

  3. 03

    ใส่ลิงก์เพลย์ลิสต์

    เลือก Configure ในส่วน General ตั้งค่า Location เป็น Remote path (Internet address) จากนั้นวางลิงก์ในช่อง M3U play list URL แล้วยืนยันด้วย OK

  4. 04

    เปิดใช้งานส่วนเสริม

    เลือก Enable หากยังไม่ได้เปิด Kodi จะโหลดช่องต่าง ๆ ถ้าช่องยังไม่แสดงทันที ลองรีสตาร์ต Kodi

  5. 05

    รับชม

    ไปที่ TV บนหน้าหลักของ Kodi ช่องจะแสดงแยกตามกลุ่ม และเปิดดูช่องใดก็ได้

เคล็ดลับ

  • Kodi เวอร์ชันใหม่ให้เพิ่มการตั้งค่าส่วนเสริมได้หลายชุด ชุดละหนึ่งเพลย์ลิสต์
  • หากเพลย์ลิสต์ของคุณลิงก์ไปยังไฟล์ EPG (XMLTV) ให้เพิ่มไว้ในการตั้งค่า EPG ของส่วนเสริมเพื่อรับผังรายการ

ลองในเบราว์เซอร์ก่อน

ไม่ต้องติดตั้งอะไร เว็บเพลเยอร์ของ Doubo เปิดช่องถ่ายทอดสดฟรีได้ทันที และเล่นลิงก์ M3U ของคุณเองได้ด้วย

เปิดเว็บเพลเยอร์

ยังไม่มีเพลย์ลิสต์?

ไดเรกทอรีช่องฟรีของ Doubo รวบรวมช่องที่ผู้แพร่ภาพเปิดให้รับชมได้แบบสาธารณะ เป็นลิงก์ M3U ที่คุณนำไปวางในเพลเยอร์ใดก็ได้

ดูช่องฟรี

คำถามที่พบบ่อย

ต้องใช้ส่วนเสริมจากบุคคลที่สามไหม?

ไม่ต้อง PVR IPTV Simple Client ดูแลโดยทีม Kodi และเพียงพอสำหรับเพลย์ลิสต์ M3U

รายการช่องว่างเปล่า ควรตรวจสอบอะไร?

ตรวจสอบว่าตั้งค่า Location เป็น Remote path ลิงก์ครบถ้วน และเปิดใช้งานส่วนเสริมแล้ว จากนั้นรีสตาร์ต Kodi
