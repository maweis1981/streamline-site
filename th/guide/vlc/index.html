คู่มืออุปกรณ์ · VLC

วิธีเปิดเพลย์ลิสต์ M3U ใน VLC (Windows, Mac, Android, iPhone)

VLC เป็นเพลเยอร์ฟรีแบบโอเพนซอร์สที่ใช้ได้แทบทุกแพลตฟอร์ม และเปิดเพลย์ลิสต์ M3U ได้ทั้งจากลิงก์และจากไฟล์ นี่คือวิธีทำบนแต่ละระบบ

สิ่งที่ต้องมี

  • VLC media player ดาวน์โหลดฟรีจาก videolan.org หรือ App Store ของอุปกรณ์คุณ
  • ลิงก์หรือไฟล์เพลย์ลิสต์ M3U / M3U8

ขั้นตอน

  1. 01

    คัดลอกลิงก์เพลย์ลิสต์

    คัดลอกที่อยู่ M3U ที่ต้องการเปิด เช่น เพลย์ลิสต์รายประเทศจากไดเรกทอรีช่องฟรีของ Doubo

  2. 02

    Windows และ Linux: Open Network Stream

    ใน VLC เลือก Media → Open Network Stream (Ctrl+N) วางลิงก์แล้วคลิก Play หากต้องการเปิดไฟล์ .m3u ที่ดาวน์โหลดไว้ ให้ใช้ Media → Open File แทน

  3. 03

    Mac: Open Network

    เลือก File → Open Network (⌘N) วางลิงก์ในช่อง URL แล้วคลิก Open

  4. 04

    Android และ iPhone: สตรีมผ่านเครือข่าย

    บน Android เปิดแท็บ More แล้วเลือก New stream (ในเวอร์ชันเก่าเรียกว่า Stream) บน iPhone และ iPad เปิดแท็บ Network แล้วเลือก Open Network Stream จากนั้นวางลิงก์และเริ่มเล่น

  5. 05

    เปลี่ยนช่อง

    VLC จะโหลดเพลย์ลิสต์ทั้งหมด บนคอมพิวเตอร์ให้เปิด View → Playlist (Ctrl+L บน Windows) เพื่อดูทุกช่อง แล้วดับเบิลคลิกช่องที่ต้องการเล่น

เคล็ดลับ

  • หากช่องไม่เริ่มเล่น ให้รอสักครู่หรือเลือกช่องถัดไป สตรีมสดบางครั้งต้องใช้เวลาบัฟเฟอร์
  • บันทึกเพลย์ลิสต์ที่ใช้บ่อยด้วย Media → Save Playlist to File เพื่อเปิดใหม่ได้โดยไม่ต้องใช้ลิงก์
  • VLC แสดงช่องเป็นรายการเรียงต่อกันธรรมดา หากต้องการกลุ่มช่อง รายการโปรด และโลโก้ช่อง ให้ใช้แอปหรือเว็บเพลเยอร์ของ Doubo

ลองในเบราว์เซอร์ก่อน

ไม่ต้องติดตั้งอะไร เว็บเพลเยอร์ของ Doubo เปิดช่องถ่ายทอดสดฟรีได้ทันที และเล่นลิงก์ M3U ของคุณเองได้ด้วย

เปิดเว็บเพลเยอร์

ยังไม่มีเพลย์ลิสต์?

ไดเรกทอรีช่องฟรีของ Doubo รวบรวมช่องที่ผู้แพร่ภาพเปิดให้รับชมได้แบบสาธารณะ เป็นลิงก์ M3U ที่คุณนำไปวางในเพลเยอร์ใดก็ได้

ดูช่องฟรี

คำถามที่พบบ่อย

VLC เปิดลิงก์ M3U8 ได้ไหม?

ได้ M3U8 คือ M3U เวอร์ชัน UTF-8 และยังใช้กับสตรีมสดแบบ HLS ด้วย VLC เปิดได้ทั้งสองแบบด้วยวิธีเดียวกัน

ทำไม VLC แสดงแค่ช่องเดียว?

คุณอาจเปิดที่อยู่สตรีมเดี่ยวแทนที่จะเป็นเพลย์ลิสต์ ตรวจสอบว่าลิงก์ชี้ไปที่ไฟล์เพลย์ลิสต์ (มักลงท้ายด้วย .m3u หรือ .m3u8) ที่มีรายชื่อหลายช่อง
