นโยบายความเป็นส่วนตัว

วันที่มีผลบังคับใช้: 12 ตุลาคม 2026

นโยบายนี้อธิบายวิธีที่แอป Doubo (“แอป”) และเว็บไซต์นี้จัดการข้อมูลของคุณ เอกสารนี้เป็นฉบับแปล หากมีข้อความใดไม่ตรงกัน ให้ถือตามฉบับภาษาอังกฤษ

1. แอป Doubo

แอปไม่เก็บหรืออัปโหลดข้อมูลส่วนบุคคลใดๆ

  • การจัดเก็บบนอุปกรณ์: URL เพลย์ลิสต์ที่คุณเพิ่ม ไฟล์เพลย์ลิสต์ที่นำเข้า รายการโปรด ช่องที่ดูล่าสุด ประวัติเพลย์ลิสต์ และการตั้งค่า จะถูกเก็บไว้บนอุปกรณ์ของคุณเท่านั้น คุณลบได้ทุกเมื่อในหน้าการตั้งค่าของแอป
  • ไม่มี SDK วิเคราะห์หรือโฆษณา: แอปไม่มีส่วนประกอบด้านการวิเคราะห์ การโฆษณา หรือการติดตามของบุคคลที่สาม
  • การเชื่อมต่อเครือข่าย: แอปจะติดต่อเฉพาะ URL ของเพลย์ลิสต์ สตรีม และโลโก้ที่คุณเพิ่มหรือเลือก เพื่อดาวน์โหลดและเล่นเนื้อหาเท่านั้น คำขอเหล่านี้ส่งตรงไปยังเซิร์ฟเวอร์ของบุคคลที่สามที่เกี่ยวข้อง ซึ่งจัดการตามนโยบายความเป็นส่วนตัวของตนเอง (เช่น อาจบันทึกที่อยู่ IP ของคุณ) เราไม่เห็นคำขอเหล่านี้
  • การตรวจสอบความพร้อมใช้งาน: เมื่อคุณตรวจสอบช่อง แอปจะส่งคำขอจำนวนเล็กน้อยไปยัง URL ของแต่ละสตรีมเพื่อดูว่าตอบสนองหรือไม่ ผลลัพธ์เก็บไว้บนอุปกรณ์ของคุณเท่านั้น
  • เครือข่ายท้องถิ่น: เมื่อคุณใช้การส่งผ่าน DLNA แอปจะค้นหาทีวีในเครือข่ายท้องถิ่นและส่ง URL ของสตรีมไปยังอุปกรณ์ที่คุณเลือก ซึ่งต้องได้รับสิทธิ์เครือข่ายท้องถิ่น และข้อมูลนี้จะไม่ออกนอกเครือข่ายท้องถิ่นของคุณ
  • การเข้าถึงไฟล์: แอปจะอ่านเฉพาะไฟล์ที่คุณเลือกเองในตัวเลือกไฟล์ของระบบเท่านั้น

2. เว็บไซต์นี้

เว็บไซต์นี้โฮสต์บน GitHub Pages และใช้ Google Tag Manager และ Google Analytics 4 เพื่อทำความเข้าใจการใช้งาน (เช่น จำนวนการเข้าชม แหล่งที่มา หน้าที่เปิดดู และการคลิกปุ่มดาวน์โหลด) เพื่อนำไปปรับปรุงเว็บไซต์

  • ข้อมูลที่เก็บ: ประเภทอุปกรณ์และเบราว์เซอร์ ตำแหน่งโดยประมาณ (ระดับเมืองหรือประเทศ) หน้าที่ส่งต่อมา หน้าที่เข้าชมและการโต้ตอบ รวมถึงตัวระบุแบบไม่ระบุตัวตนที่เก็บไว้ในคุกกี้ Google Analytics 4 ไม่บันทึกหรือจัดเก็บที่อยู่ IP แบบเต็ม
  • คุกกี้และการให้ความยินยอม: เราใช้ Google Consent Mode ในเขตเศรษฐกิจยุโรป สหราชอาณาจักร และสวิตเซอร์แลนด์ คุกกี้เพื่อการวิเคราะห์จะถูกตั้งค่าหลังจากคุณคลิก “ยอมรับ” เท่านั้น ในพื้นที่อื่น คุณคลิก “ปฏิเสธ” ได้ทุกเมื่อเพื่อปิดคุกกี้เพื่อการวิเคราะห์ ส่วนการจัดเก็บเพื่อการโฆษณาปิดอยู่เสมอ คุณเปลี่ยนตัวเลือกได้ทุกเมื่อผ่าน “การตั้งค่าคุกกี้” ที่ส่วนท้ายของหน้า
  • ผู้ประมวลผลข้อมูล: ข้อมูลการวิเคราะห์ประมวลผลโดย Google LLC ดูนโยบายความเป็นส่วนตัวของ Google และวิธีที่ Google ใช้ข้อมูลจากเว็บไซต์ที่ใช้บริการของ Google คุณยังติดตั้งส่วนเสริมเบราว์เซอร์เพื่อเลือกไม่ใช้ Google Analytics ได้
  • การโฮสต์: GitHub ในฐานะผู้ให้บริการโฮสต์ อาจบันทึกที่อยู่ IP ของผู้เข้าชมเพื่อความปลอดภัยและการดำเนินงาน ดูคำแถลงความเป็นส่วนตัวของ GitHub
  • ระยะเวลาการเก็บรักษา: ข้อมูล Google Analytics จะถูกเก็บไว้ 14 เดือน

3. ความเป็นส่วนตัวของเด็ก

แอปและเว็บไซต์นี้ไม่ได้มุ่งเป้าไปที่เด็กอายุต่ำกว่า 13 ปี และเราไม่ได้ตั้งใจเก็บข้อมูลส่วนบุคคลของเด็ก

4. ทางเลือกของคุณ

คุณลบข้อมูลของแอปบนอุปกรณ์หรือลบแอปได้ทุกเมื่อ สำหรับการวิเคราะห์เว็บไซต์ คุณปฏิเสธหรือถอนความยินยอมเรื่องคุกกี้ได้ หากมีคำถามหรือคำขอเกี่ยวกับการจัดการข้อมูล ติดต่อเราผ่านหน้าช่วยเหลือ

5. การเปลี่ยนแปลง

เมื่อนโยบายนี้มีการเปลี่ยนแปลง เราจะอัปเดตวันที่มีผลบังคับใช้ในหน้านี้ การเปลี่ยนแปลงที่สำคัญจะแจ้งไว้บนเว็บไซต์หรือในบันทึกประจำรุ่นของแอป
