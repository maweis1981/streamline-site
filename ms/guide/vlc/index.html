Cara Main Senarai Main M3U dalam VLC (Windows, Mac, Android, iPhone)

VLC ialah pemain media percuma dan sumber terbuka untuk hampir semua platform, dan ia boleh membuka senarai main M3U daripada pautan atau fail. Begini caranya pada setiap sistem.

Apa yang anda perlukan

  • VLC media player, percuma dari videolan.org atau gedung aplikasi peranti anda
  • Pautan atau fail senarai main M3U / M3U8

Langkah-langkah

  1. 01

    Salin pautan senarai main

    Salin alamat M3U yang ingin anda mainkan, contohnya senarai main mengikut negara daripada direktori saluran percuma Doubo.

  2. 02

    Windows dan Linux: Open Network Stream

    Dalam VLC, pilih Media → Open Network Stream (Ctrl+N), tampal pautan dan klik Play. Untuk membuka fail .m3u yang telah dimuat turun, gunakan Media → Open File.

  3. 03

    Mac: Open Network

    Pilih File → Open Network (⌘N), tampal pautan ke dalam medan URL dan klik Open.

  4. 04

    Android dan iPhone: strim rangkaian

    Di Android, buka tab More dan pilih New stream (dipanggil Stream dalam versi lama). Di iPhone dan iPad, buka tab Network dan pilih Open Network Stream. Tampal pautan dan mulakan main balik.

  5. 05

    Tukar saluran

    VLC memuatkan keseluruhan senarai main. Pada komputer, buka View → Playlist (Ctrl+L di Windows) untuk melihat setiap saluran dan klik dua kali pada satu saluran untuk memainkannya.

Petua

  • Jika saluran tidak bermula, tunggu beberapa saat atau pilih saluran seterusnya; strim langsung kadangkala mengambil sedikit masa untuk menimbal.
  • Simpan senarai main yang kerap anda gunakan dengan Media → Save Playlist to File supaya anda boleh membukanya semula tanpa pautan.
  • VLC memaparkan saluran sebagai senarai rata. Untuk kumpulan, kegemaran dan logo saluran, gunakan aplikasi Doubo atau pemain web.

Cuba dalam pelayar anda dahulu

Tiada pemasangan diperlukan. Pemain web Doubo terus membuka saluran langsung percuma, dan turut memainkan pautan M3U anda sendiri.

Buka pemain web

Perlukan senarai main?

Direktori saluran percuma Doubo menyenaraikan saluran yang disediakan secara terbuka oleh penyiar, sebagai pautan M3U yang boleh anda tampal ke dalam mana-mana pemain.

Layari saluran percuma

Soalan

Bolehkah VLC membuka pautan M3U8?

Ya. M3U8 ialah versi UTF-8 bagi M3U dan juga digunakan untuk strim langsung HLS; VLC membuka kedua-duanya dengan cara yang sama.

Kenapa VLC hanya menunjukkan satu saluran?

Anda mungkin membuka satu alamat strim sahaja dan bukannya senarai main. Pastikan pautan berakhir dengan fail senarai main (selalunya .m3u atau .m3u8) yang menyenaraikan banyak saluran.
