Muat turun

Pemain M3U dalam talian percuma, terus boleh guna

Doubo versi web ialah pemain M3U / M3U8 dalam talian yang percuma. Tanpa muat turun dan tanpa daftar: tampal pautan senarai main atau import fail, kemudian layari kumpulan, cari dan tonton saluran langsung dalam pelayar komputer atau telefon.

  • Tiada pemasangan

    Berfungsi dalam Chrome, Edge, Safari, Firefox dan pelayar moden lain.

  • Kumpulan dan carian

    Membaca kumpulan dalam senarai main supaya anda cepat menemui saluran walaupun ada ribuan.

  • Tukar laluan secara automatik

    Saluran dengan beberapa pautan strim digabungkan, dan pemain beralih ke pautan seterusnya jika satu tidak bermula.

  • Privasi diutamakan

    Senarai main kekal dalam pelayar anda. Tiada apa-apa dimuat naik atau dikumpul.

Soalan lazim

Adakah pemain web ini percuma? Perlukah akaun?

Ia percuma sepenuhnya dan tidak memerlukan akaun. Buka halaman, tambah senarai main dan mula menonton.

Format senarai main apa yang disokong?

Senarai main M3U dan M3U8, termasuk senarai IPTV dengan atribut tvg-id, tvg-logo dan group-title. Strim langsung dimainkan melalui HLS (.m3u8).

Di mana senarai main saya disimpan?

Hanya dalam storan setempat pelayar anda. Ia tidak pernah dimuat naik. Jika anda menukar pelayar atau memadam data laman, tambahkannya semula.

Mengapa sesetengah saluran lebih baik ditonton dalam aplikasi?

Atas sebab keselamatan, pelayar mengehadkan sesetengah strim langsung, seperti pautan http atau laluan yang memerlukan pengepala khas. Aplikasi Doubo tiada had ini dan turut menyokong pancaran ke TV serta main balik latar.
